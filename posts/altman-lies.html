On Altman's Lies and Journalism

23.6.2025

Did Altman lie when

In this blog post Sam Altman put forth the preposterous, possible even dangerous and especially uncited claim that an average ChatGPT query uses about 0.34 Watt-hours. While my initial though was, huh, nice, seems about right.

This number has been questioned quite a lot: TODO articles here

Most queries for chatgpt are using gpt4o or gpt4o-mini. gpt4o is about 200B params: https://arxiv.org/pdf/2412.19260v1

Supermicro https://smicro.eu/nvidia-delta-next-hgx-gpu-baseboard-8-h100-80gb-sxm5-935-24287-0000-000-1

- 8x H100 nodes uses 5600W - Average chatgpt query answer takes 5 seconds - Artificialanalysis says gpt-40 can do about 200 tokens/second Other: - Average chatgpt query is 23 words - Average output length 500 tokens 


0.34 Wh = 5600W * 5 seconds / batch size

What can we expect from tech journalists? Should they be able to do this? I do think large outlets should employ at least some people capable of this analysis. Might be deliberate to drive clicks through hatred.
